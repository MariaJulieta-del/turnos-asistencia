# apps/web

Pendiente. App instalable (PWA) con dos vistas:

- **Dueño:** grilla mensual de turnos, aprobación de cambios, anomalías de fichaje, reporte de horas.
- **Empleado:** mi horario, botón de fichar (con cola offline), pedir cambio de turno.

Debe usar `@turnos/core` para todo cálculo. Ver `docs/ARQUITECTURA.md`.
